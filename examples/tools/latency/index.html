Every off-diagonal cell is (rttA + rttB) / 2 — a peer's true one-way latency, estimated by halving each side's own round trip to the server. That assumes a symmetric path, and real networks often aren't symmetric, so treat the matrix as an estimate. The observed column measures actual one-way transit for each peer update (using clock-skew-corrected timestamps from worlds.ws.ping()), so you can see how far reality drifts from the estimate — that gap is mostly server-side queueing, not propagation.
